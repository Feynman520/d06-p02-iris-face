# IRIS-Face 설계 v1 (2026-09-08, 사용자 확정 조각 ①~④ 통합)

## 0. 정체와 불변 원칙

IRIS의 얼굴. 클로드코드·코덱스 세션 여러 개를 한 창에 모아 지휘하는 데스크톱 앱(베타·선택 수단·폐기 가능).

1. **현재 시스템 무접촉.** CLI·프록시(TeamClaude 3456)·구독·`settings.json`·`config.toml`·AGENTS.md 상속·메모리·훅·MCP를 바꾸지 않는다. Face는 폴더 1개 + 루트 바로가기 1개 + 포트 3458 데몬만 더한다. 기록파일은 읽기만 한다.
2. **폴더는 사용자가 고른다.** 자동 폴더 선택은 폐기(스파이크 3위 안 40%).
3. **세션은 사용자가 닫을 때만 닫힌다.** 창을 닫아도 유지.
4. **터미널 직접 타이핑은 라우터를 거치지 않는다.** Face 입력창 요청만 라우팅.
5. **역할 분담.** 클로드 = 머리(지휘·판단·설계·글·최종 검토), 코덱스 = 손(구현·테스트·터미널·이미지 생성·read-only 코드 리뷰), Face = 책상(배정·손 전달). 시작 비중 약 8:2, 로그로 조정.
6. **프로세스 종료는 PID로만.** 이름 기반 종료 코드 금지.

## 1. 구성

```text
IRIS-Face.cmd(루트) → launch.mjs → [daemon/server.mjs :3458] ← [app/ Electron 창 + 트레이]
                                          │ node-pty 세션들(claude/codex, 기존 별칭 그대로)
                                          │ 기록파일 감시(projects\*.jsonl, sessions\rollout-*.jsonl)
                                    [router/] 판정(규칙표 → Haiku 보조) · 조합 실행기(슬래시 주입·--agents·짝 작업·한도)
```

폴더: `daemon/` `app/` `router/` `agents/`(face-* 도구 세트) `docs/` `state/`(sessions.json·PID·로그, git 제외).

## 2. 조각 ① 세션 데몬

- 127.0.0.1:3458, PID 파일 `state/daemon.pid`, 단일 실행. 외부 접속 불가.
- 세션 생성 입력 = 폴더·별칭·첫 요청문(선택). `cmd.exe /c <별칭>.cmd` 를 node-pty(ConPTY)로, 환경변수 상속(사용자 수준 `ANTHROPIC_BASE_URL`·`CLAUDE_CONFIG_DIR`·`CODEX_HOME` 확인됨).
- 클로드는 `--session-id <UUID>`를 미리 지정해 기록파일명 확정, 코덱스는 시작 출력의 `session id:`를 읽어 롤아웃 파일 연결.
- 세션 정보(번호·폴더·별칭·현재 조합·시작 시각·PID·기록파일 경로) = `state/sessions.json`.
- 출력 실시간 전달 + 마지막 200KB 보관(복원용). 입력 = 앱 입력창/터미널 타이핑 모두 같은 통로.
- 상태: ● 작업 중(2초 내 출력) / ○ 대기 / ⚠ 확인 필요(출력 멈춤 + 프롬프트 패턴, 추정) / ✕ 종료.
- 세션 닫기 = 명시 요청 + 그 PID만. 데몬 종료 = 트레이 "전부 종료"(세션 수 확인).
- 로그 = 생성·종료·조합 선택만. 대화 내용 미기록.
- 재부팅 뒤: sessions.json의 죽은 세션은 "이전 세션(재개 가능)"으로 표시 → `claude --resume` / `codex resume`.

## 3. 조각 ② 기록파일 → 대화 화면

- 꼬리 읽기(크기 변화 감시, 새 줄만 파싱). 쓰기 없음.
- 매핑: 내 요청(user 글) → 오른쪽 말풍선 / 답변 text → 왼쪽 말풍선(마크다운 렌더, 내장 변환기, CDN 없음) / tool_use·function_call → 접힌 한 줄 / tool_result → 붙여 표시(20줄+더 보기) / thinking·reasoning → 회색 접힘 / AskUserQuestion·⚠ → 노란 카드 "터미널에서 답해 주세요" / 서브에이전트(isSidechain·별도 롤아웃) → "↳ 보조 작업 N개" / usage·token_count → 머리에 작게 / isMeta·system-reminder·developer·environment_context → 숨김.
- `compacted`·요약 항목 → "이전 대화 요약됨" 구분선.
- 최근 300항목만 렌더, 위로 스크롤 시 추가. 모르는 항목은 "알 수 없는 항목 N개"로 접음.
- 터미널 보기 토글(xterm.js, 한글 고정폭 폰트).

## 4. 조각 ③ 요청 라우터 (층 1) + ③-b 조합 실행기

### 판정 대상
(조합 4종: 클로드 단독 / 코덱스 단독 / 클로드 어드바이저+코덱스 워커 / 코덱스 어드바이저+클로드 워커) × 클로드 모델·effort × 코덱스 모델·effort.

### 판정 절차
요청문 → 규칙표(`조합-규칙표.md` 3절, 동사·키워드) → 확신 높으면 바로, 애매하면 Haiku 1회(`claude -p --tools "" --strict-mcp-config --disable-slash-commands --setting-sources user --model haiku`, ≈1.5천 토큰·5초, 프록시 경유) → 힌트 단어("꼼꼼히·최고로·빨리·대충") 덮어쓰기 → 한도 인지(TeamClaude 상태 읽기: Fable 주간 50% 캡·Astra 5시간 캡·클로드 주간 사용률 높으면 한 단계 내리고 코덱스로 기울임) → 입력창 위 한 줄 표시 [보내기][바꾸기].
추가 규칙: 이미지 생성·편집 → 코덱스 워커(구독 한도, 실측 후 확정). 개발 P(R07) 안에서는 코덱스 후보를 함께 표시.

### 새 작업 마법사 = 세션이 없을 때의 라우터
1단 폴더(graph.json 559개+루트, 퍼지 검색, 코드 입력, 최근 5개 상단, 신선도 배지, 살아 있는/재개 가능 세션 안내) → 2단 요청문(비우면 세션만) → 3단 조합 확정.

### 조합 실행기(③-b)
1. 슬래시 주입: 세션 ○(1.5초 무출력 + 프롬프트 패턴)일 때만, 현재 조합과 다른 항목만 `/model X⏎`·`/effort Y⏎` → 화면 반응 확인 → 요청⏎. ●면 대기열. 실패 시 중단·알림. 코덱스 `/model` 한 줄 주입 가능 여부는 구현 첫날 실측, 불가 시 코덱스는 세션 단위 고정(새 세션으로 대체).
2. 위임 도구 세트(층 2): Face가 연 클로드 세션에만 `--agents` JSON 부착. `face-explorer`(Haiku, Read·Grep·Glob) · `face-drafter`(Sonnet medium, Read·Write·Edit) · `face-codex-worker`(Bash, `codex exec --sandbox workspace-write -C <폴더> -m gpt-5.6-terra -c model_reasoning_effort=medium`) · `face-codex-reviewer`(Bash, `codex exec --sandbox read-only …` APPROVED/WARNING/BLOCKED). 첫 프롬프트 앞에 위임 정책 단락(탐색→explorer, 초안→drafter, 구현·테스트·이미지→codex-worker, 리뷰→codex-reviewer, 판단·종합은 직접, xhigh 승격은 사용자 확인, 위임 중 직접 편집 금지).
3. 짝 작업(코덱스 어드바이저+클로드 워커): Face가 `codex exec --sandbox read-only -o <폴더>\.iris-face\plan-N.md`를 배경 작업으로 실행(사이드바 "↔"), 완료 시 파일 내용을 클로드 세션 입력으로 전달. 리뷰도 동일.
4. 기록: 요청마다 `폴더·요청문 앞 80자·판정·최종·바꿨는지·시각`. 월 단위 집계로 규칙표 갱신(한 번에 한 다이얼).

### 한계(명시)
어드바이저 자신의 모델·effort는 턴 도중 변경 불가(턴 사이만). 위임 품질 = 정책 문장 품질. 코덱스 어드바이저는 클로드 워커를 직접 못 부름(짝 작업으로만).

## 5. 조각 ④ 앱 창·트레이·바로가기

- 흐름: `IRIS-Face.cmd` → launch.mjs(데몬 없으면 분리 실행, 버전 불일치면 재시작 제안) → Electron 창 → 세션 복원. 창 X = 트레이 숨김. 트레이: 창 열기·세션 N개·전부 종료(확인).
- 화면: 사이드바(세션 카드: 폴더·에이전트·모델·effort·상태, 짝 "↔", [＋ 새 작업], 한도 요약) / 가운데(대화 화면 기본, 터미널 토글, "외부에서 재개" 버튼) / 입력창(여러 줄, Ctrl+Enter, 판정 한 줄, 마이크·카메라 자리만).
- 단축키: Ctrl+1~9 세션, Ctrl+N 새 작업, Ctrl+T 터미널, Esc 입력창.
- 설치: 프로젝트 내 `npm install`(Electron·node-pty·xterm.js ≈250MB), 인스톨러 없음. 폐기 = 폴더·바로가기 삭제.
- 디자인: frontend-design 지침, 대시보드와 같은 테마 계열.

## 6. 조각 ⑤ (범위 밖) 마이크·카메라 — 아이콘 자리만. 카메라는 로컬 캡처→파일→경로 삽입 예정, 마이크는 전사 경로(브라우저 내장/OpenAI 키) 별도 결정.

## 7. 검증 기준(완료 정의)

1. 데몬: 세션 3개 생성·입력·출력·닫기, 창 종료 후 재접속 시 복원, 재부팅 시나리오(죽은 세션 재개 표시).
2. 대화 화면: 클로드·코덱스 실세션 기록으로 말풍선·도구·서브에이전트 렌더, 숨김 항목 미노출.
3. 라우터: 규칙표 20문장 시험(판정 일치), Haiku 폴백 동작, 힌트 단어 덮어쓰기, 한도 인지(프록시 꺼짐 시 생략).
4. 실행기: 클로드 `/model`·`/effort` 주입 후 `/model` 표시 확인, `--agents` 도구 세트로 위임 발생 확인, 짝 작업 파일 전달, 코덱스 `/model`·이미지 생성 실측 결과 기록.
5. 무접촉 검증: Face 사용 전후 `settings.json`·`config.toml`·전역 agents 폴더 해시 동일. 터미널 직접 세션 동작 동일.
6. 프로세스: 세션 닫기·전부 종료가 PID 기준인지 코드 검토. 이름 기반 종료 없음.
