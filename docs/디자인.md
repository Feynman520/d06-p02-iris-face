# IRIS 화면 디자인 v2 (2026-09-09, UI/UX 개편)

사용자 지시: 헤더 "IRIS" · 화면 중앙에 수많은 작은 별이 모여 움직이는 세련된 애니메이션 · 아래 입력창 · 입력창의 폴더 아이콘 → 트리 → 폴더 선택 → 요청 전송으로 새 세션 · 연결 상태는 초록 불 하나.

## 1. 개념 — "별의 홍채"

IRIS(홍채)라는 이름을 그대로 화면의 단 하나의 볼거리로 쓴다. 수천 개의 작은 별이 **홍채 고리**를 이루어 반지름마다 다른 속도로 천천히 돈다(안쪽이 빠른 차등 회전 = 홍채 섬유결). 동공(중심)은 비어 있고, 마우스가 가까우면 살짝 열린다. 처음 1.2초에 흩어진 별이 고리로 모이는 연출은 한 번뿐이다. 세션이 작업 중이면 흐름이 조금 빨라지고, 대화 화면이 열리면 뒤로 물러나 어두워진다. `prefers-reduced-motion`이면 정지 화면.

레퍼런스에서 걸러낸 것: "점을 선으로 잇는 네트워크"는 2026년에도 가장 흔한 기본형이라 쓰지 않았다. 색은 Raycast·Linear 계열처럼 98% 무채색에 강조색 하나(홍채 청보라)만 두고, 표면은 4단계(base < surface < raised < overlay)와 얇은 선으로 층을 만든다.

## 3. 배치

```text
┌ ● IRIS ──────────────────────────────── 한도 요약  ☰ ┐  48px
├ 세션 레일 248px ┬ 무대 ───────────────────────────────┤
│ ● IRIS  1      │            (별의 홍채)                │
│   cl-quick …   │        안내 한 줄 / 대화 / 터미널       │
│                │  판정 한 줄(세션 모드에서만)            │
│ + 새 요청  전부 종료 │ [📁 폴더칩] 요청문 …  [조합칩] (↑) │  도크
└────────────────┴──────────────────────────────────────┘
```

- **도크(입력창)** 는 화면 아래 고정, 폭 880px 가운데, 반투명 유리판. 왼쪽 폴더 버튼 = 아이콘 + 고른 폴더 이름. 오른쪽 조합 칩(판정 결과, 누르면 다른 조합 선택) + 보내기 원형 버튼.
- **새 요청 모드**(세션 미선택): 폴더 고르기 → 요청 → Ctrl+Enter → Haiku 포함 판정 → 세션 생성·선택. 폴더 없이 보내면 트리가 열린다.
- **세션 모드**: 같은 입력창이 그 세션으로 보낸다. 폴더 칩은 세션 폴더로 잠기고, 누르면 다른 폴더에서 새 요청 모드로 전환. 판정이 현재 조합과 다르면 입력창 위 한 줄에 [바꾸고 보내기]·[↔ 코덱스 계획 먼저].
- **폴더 트리 팝오버**: 검색(코드·낱말) + 최근 5개 칩 + R → D → P 접기/펴기, 살아 있는 세션 배지, 온톨로지 신선도 점.
- 단축키: Ctrl+O 폴더, Ctrl+N 새 요청, Ctrl+B 레일, Ctrl+T 터미널, Ctrl+1~9 세션, Esc 입력창.

## 3-b. v2.1 조정 (2026-09-09 사용자 피드백)

- 무대의 안내 문장 전부 삭제(별의 홍채와 입력창만). 폴더 버튼은 **아이콘만**(고르면 청보라로 켜지고, 입력창 아래 작은 회색 경로 한 줄). 입력창 placeholder 없음.
- 레일 접기(☰)는 **레일 안 왼쪽 위**. 접으면 52px 미니 레일(☰·세션 점·＋·⏻만). 전부 종료 = **빨간 전원 아이콘**.
- **Enter = 보내기, Ctrl+Enter·Shift+Enter = 줄바꿈**(한글 조합 중 Enter는 무시).
- 화면에 별칭(cl-quick 등) 대신 **원래 이름**("Claude Sonnet 5 · low", "Codex gpt-5.6-terra · high · 읽기 전용"). 조합 메뉴는 이름 + 용도 한 줄. 별칭은 데몬 내부·런처 파일 이름으로만 남는다.
- 대화 열 최대 1180px(말풍선 92%).
- 작업 중에는 대화 아래에 **활동 한 줄**(CLI 스피너 문구 "Cogitating… 12s" 그대로, 점 3개 깜박임). 모델의 생각 내용은 기록파일에 비어 오므로(비공개) 보여 줄 수 없다.
- 보조 작업 완료 알림(`<task-notification>`)과 "Async agent launched" 내부 결과는 사용자 말풍선으로 그리지 않는다(요청이 3개로 보이던 원인).

## 3-c. v2.2 조정 (2026-09-09 두 번째 피드백)

- 홍채 고리 → **별의 구(球)**: 피보나치 구 표면 70% + 안쪽 25% + 산개 5%, 원근 투영(앞은 크고 밝게), 두 축 회전 + 적도 띠가 더 빨리 흐름, 마우스가 기울기를 바꿈, 작업 중이면 회전 가속.
- 첫 입력창 placeholder "폴더를 고르고 요청을 적어 주세요"(폴더를 고르거나 세션을 선택하면 사라짐).
- 레일 제목 "세션" → "작업목록".
- 입력창 오른쪽 아이콘 3개: 🎤 음성(준비 중, 흐리게) · 📷 카메라(웹캠 미리보기 → 찍기 → PNG 업로드) · 🖼 사진·파일(파일 선택 → 업로드). 업로드는 `POST /api/upload` → `state/uploads/` 저장, 요청문 끝에 `[첨부 파일]` 경로 목록으로 붙여 CLI에 전달(두 CLI 모두 경로로 이미지를 읽는다).
- **TeamClaude 대시보드(3457) 연결**: 상단 한도 요약을 누르면(Ctrl+D) 오른쪽 서랍에 대시보드 페이지를 iframe으로 띄운다(새로고침·브라우저에서 열기·닫기). 대시보드 서버는 그대로 두고 화면만 빌려 오는 방식이라 서로 독립적이다(무접촉).

## 3-d. v2.3 (2026-09-09 낮) — 자동 판정 폐기 후 배치

- 입력창 **위 한 줄** = [📁 폴더 이름] [Claude | Codex] [모델 ▾] [사고깊이 ▾] (Codex면 □ 읽기 전용). 폴더 버튼은 이 줄의 맨 왼쪽, 고르면 이름이 표시된다. 세션이 열리면 이 줄이 잠기고 "이 세션: …"이 오른쪽에 뜬다.
- 입력창 오른쪽 아이콘 4개: 🎤 음성(준비 중) · 📷 카메라 · 🖼 사진(이미지만) · 📎 파일(모든 파일). 첨부는 업로드 후 요청문 끝에 경로 목록으로 붙는다.
- 조합 칩·판정 줄·경로 캡션은 없다.

## 3-e. v2.4 — 차례(turn) 렌더와 삽입물 (2026-09-09 낮)

- 대화는 **차례 단위**: 내 요청 → 과정(생각·도구 호출·결과·중간 답) → 최종 답. 진행 중엔 과정의 **최신 한 단계만** 아래에서 위로 부드럽게 넘어오며 보이고(이전 단계는 지나감), 세션이 대기로 돌아오면 과정이 **"과정 N단계"** 한 줄로 접힌다(눌러 펼침). 생각 본문은 기록에 비어 오면 "(추론 내용 비공개)".
- **삽입물**: 답·도구 결과·요청문에 든 로컬 이미지 경로(png/jpg/gif/webp/svg)는 그 자리에 그림으로, 로컬 `.html` 파일과 `127.0.0.1/localhost` 주소는 그 자리에 iframe으로 끼워 넣는다(각각 "새 창" 버튼). 파일은 데몬의 `GET /api/file?path=`가 서빙(이미지·HTML·PDF·텍스트만, Windows·Program Files 폴더 금지). 첨부해 보낸 이미지는 내 말풍선 안에 썸네일로.
- 조합 바꾸기는 **같은 에이전트 안에서만**(모델·사고깊이). Claude↔Codex 전환은 서로 다른 프로그램·기록 형식이라 같은 세션으로는 불가 — 새 세션을 열고 이전 대화를 요약해 넘기는 "맥락 옮기기"는 미구현(원하면 추가).

## 3-f. v2.5 — 에이전트 바꾸기(맥락 이어받기)·조합 아이콘·헤더 마크 (2026-09-09 오후)

- **조합 바꾸기 = 입력창 오른쪽 조절(슬라이더) 아이콘.** 누르면 입력창 위에 [Claude|Codex] [모델] [사고깊이] 줄이 '이어가기' 모드로 나타나고 [이 조합으로 이어가기] / [취소]. 세션 모드에서 조합 줄은 평소에 감춰진다("이 세션: …" 문구 삭제).
- **같은 에이전트**: `--resume`/`codex resume`로 같은 대화 재개(맥락 그대로). **다른 에이전트**: 데몬이 지금까지의 요청·답·도구 호출을 글로 묶어(최근 8천 자, `buildHandoff`) 새 CLI의 첫 요청으로 넘긴다("[이전 대화 이어받기 — Claude Sonnet 5 · low 세션에서 옮겨 옴 …]"). 같은 카드가 유지되고 이전 세션 정보는 `previous[]`에 남는다. 실측: Claude Sonnet → Codex terra 전환 뒤 코덱스가 "오늘의 암호는 파란 사과"를 기억함. 단 코덱스 첫 답은 MCP 기동(notebooklm 실패 대기)으로 최대 3분까지 걸릴 수 있다.
- **헤더 마크**: IRIS 앞에 두 고리가 서로 반대로 천천히 돌고 중심이 숨 쉬는 SVG(청보라 그라디언트). 연결 초록 점은 IRIS 뒤로.

## 3-h. v2.6 — 꾸미기 설정(⚙)·영혼 폴더 이름·사용량 배터리 (2026-09-09 저녁)

- **설정 패널(⚙, Ctrl+,)**: 헤더 이름(비우면 영혼 폴더 이름) · 헤더 마크 21종(살아 움직이는 미리보기, 속도 0.5~2×) · 글자체 24종(이 PC 설치 글꼴) · 테마 7종(CSS 변수 묶음: 남색 밤·순검정·그래파이트·깊은 숲·잿불·보랏빛·밝은 종이) · 중앙 애니메이션 6종(별의 구·별의 홍채·성운·별자리·잔잔한 별밭·없음) + 별의 양 + "대화 보는 동안 멈춤". 후보 목록 = `app/registry.js`, 적용 = `app/settings.js`. 저장 = localStorage + 데몬 `state/settings.json`(브라우저·Electron 공유).
- **영혼 폴더 이름**: 데몬 `workspace.mjs`가 Face 폴더에서 위로 올라가며 `_ontology\graph.json` 또는 `_agent\`가 있는 폴더를 루트로 찾아(`IRIS_ROOT` 환경변수가 있으면 우선) `/api/health.rootName`으로 준다. 다른 사용자가 `D:\MySoul\…`에 설치하면 헤더가 "MySoul"이 된다. 폴더 선택기의 루트도 같은 값.
- **사용량 배터리**: 헤더 오른쪽에 Claude·Codex 주간 사용률을 배터리 막대로(60% 초과 노랑, 85% 초과 빨강, 툴팁에 Fable·5시간·계정). 누르면 TeamClaude 대시보드 서랍.
- **성능**: 고르지 않은 후보는 아예 만들어지지 않는다(패널을 열었을 때만 미리보기 21개가 돌고 닫으면 제거). 실제 비용은 중앙 캔버스 하나뿐 — 별의 구 3천 개 기준 이 PC에서 GPU 합성 포함 CPU 2~4%, 창을 숨기거나 다른 탭이면 0. 별의 양 슬라이더·"없음"·"대화 중 멈춤"으로 더 줄일 수 있다. 헤더 마크(SVG 요소 3~6개)·테마(변수 교체)는 측정치 이하로 무시해도 된다.

- **함정(R-010 계열, 해결함)**: win32com의 makepy가 gen_py 캐시를 만들 때 경로에 든 `〖`(U+3016)를 cp949 콘솔로 print 하다 죽어, win32com.client가 반쯤 초기화된 채 다음 접근에서 순환 import로 실패했다. 자식 프로세스를 `PYTHONUTF8=1`·`PYTHONIOENCODING=utf-8`로 띄워 막았다(손상된 gen_py 캐시는 한 번 지움). 실 데몬은 이 새 코드가 **재시작 후** 적용된다.

## 3-q. v2.15 — 코덱스는 항상 fast, 세션 여는 중 표시 (2026-09-09 밤)

**코덱스 fast 항상 켬(사용자 결정).** 코덱스의 `/fast`는 설정값 `service_tier = "fast"`다(코덱스 0.153.4 바이너리에서 `service_tier`가 ThreadSettings 키로 확인, 사용자 `config.toml` 9행에도 이미 `service_tier = "fast"`가 있음 — 터미널에서 /fast를 켠 흔적). Face는 설정 파일을 건드리지 않는 원칙이므로 **시작 플래그 `-c service_tier=fast`를 항상 붙여** 설정이 바뀌어도 Face 세션은 늘 fast다. 세션 머리 권한 표시에 `⚡ fast`를 앞세운다. 프록시(TeamClaude)는 본문을 손대지 않으므로 그대로 통과. 클로드코드에도 `/fast`가 있다(Opus 4.8/5 전용 — 더 빠른 출력, Fable·Sonnet은 대상 아님; 바이너리에 `fastMode` 설정 키·`fastModePerSessionOptIn` 확인). **→ 2026-09-10 사용자 결정: 클로드도 가능한 모델은 항상 fast.** 구현: Face 소유 파일 `state\fast-mode.json` = `{ "fastMode": true }`를 **Opus 세션에만** `--settings <그 경로>`로 넘긴다(`--settings`는 user 설정보다 우선, settings.json 무접촉). Fable·Sonnet·Haiku는 fast 대상이 아니라 붙이지 않는다(붙이면 "Fast mode is not available" 소음만 남). 경로에 공백·한글·`〖〗`가 있어도 `cmd.exe /c`를 거쳐 그대로 도착함을 node-pty로 실측(`scratchpad/pty_quote_test.mjs`, SAME=true) — 이것으로 "긴 한글 인자 위험"은 **경로 한 개 인자**에 한해 해제. 세션 머리에 `⚡ fast` 표시(Opus·코덱스). fast 모드에는 별도 속도 제한이 있어(바이너리 `fastModeRateLimit…`) 걸리면 클로드코드가 스스로 일반 모드로 내려간다.

**세션 여는 중 표시.** 새 요청 뒤 기록파일이 생길 때까지(CLI가 MCP·스킬·컨텍스트를 불러오는 10~60초) 화면이 비어 멈춘 듯 보였다. 해결: `Transcript.prime(text)` — 세션 생성 직후 내 요청문 말풍선과 "세션 여는 중 — 도구와 컨텍스트를 불러옵니다 (첫 답변은 최대 1분)" 진행 표시를 **바로** 그린다. 기록이 비어 있는 동안은 `render([])`가 이 표시를 유지하고, 진짜 기록이 도착하면(`append`/`render`) 치운다(중복 방지). 기록이 0개인 채로 작업 중이면 "생각 중" 대신 같은 안내를 쓰고, 첫 요청 전달 직전에 잠깐 대기로 바뀌는 깜빡임은 무시한다. 파일: `app/transcript.js`, `app/main.js`(submit), `daemon/agents.mjs`.

## 3-r. v2.16 — 작업목록 세션 이름 = 첫 요청의 짧은 제목 (2026-09-10)

**요청(사용자).** 레일(작업목록)의 세션 줄이 폴더 이름만 보여 어느 세션이 무슨 일인지 알 수 없었다. "최초 요청의 아주 짧고 명확하고 직관적인 세션 이름"으로 보이게 한다.

**결정 — 두 겹, 새 AI 호출 없음.**

| 순위 | 재료 | 언제 보이나 | 근거 |
|---|---|---|---|
| 1 | 클로드코드가 기록파일에 스스로 적는 `ai-title` 줄(예: `IRIS Face 사이드바 세션 이름`) | 첫 답변 뒤 몇 초 | 이미 236개 기록에 존재 — 무접촉 원칙 그대로, 추가 토큰 0 |
| 2 | 첫 요청문에서 뽑은 한 줄(`daemon/title.mjs`) | 세션을 만드는 순간 즉시 · 코덱스는 이것이 최종 | 안내문·위임 정책·첨부 목록·코드 블록 제거 → 첫 문장 → "해줘/주세요/부탁드립니다" 꼬리 제거 → 24자(낱말 경계) |
| — | 둘 다 없으면 폴더 이름(종전 표시) | 빈 세션 | |

- 레코드 필드 `title`·`titleSource`(`first`→`ai`; 이어받기 뒤는 `fixed`로 잠가 "이전 대화 이어받기" 같은 요청문이 이름을 덮지 않게). `sessions.json`에 저장되므로 죽은·외부 소유 세션도 이름을 유지하고, 데몬을 새로 켜면 기록파일을 처음부터 읽어 옛 세션도 이름이 채워진다.
- 데몬: `transcript.mjs`가 `ai-title`(가장 최근 값)과 첫 사용자 요청문을 기억 → `server.mjs` `syncTitle`(1.5초 폴링 안)이 `sm.setTitle`로 갱신·저장·목록 방송. ai 제목은 48자, 요청문 제목은 24자에서 자른다(레일은 CSS 말줄임, 툴팁에 전체).
- 화면: 레일 첫 줄 = 제목(없으면 폴더), 둘째 줄 = **폴더 이름** · 에이전트 · 모델 · 사고깊이 · 상태. 세션 머리도 제목이 앞, 폴더는 조합 줄 앞으로.
- 검증: 제목 규칙 10건 통과, 시험 데몬(3459·임시 state)에서 실제 기록파일로 `ai` 제목 자동 채움 + `fixed` 보존 확인. **실 데몬은 ⏻ 전부 종료 뒤 다시 실행해야 적용.**
